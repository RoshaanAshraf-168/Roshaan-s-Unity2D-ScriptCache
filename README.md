A collection of foundational scripts to be easily used across multiple projects.

- Includes a player melee script with 2 distinct attacks (Primarily Knockback attack / Primarily Damage attack)!
- Includes an Intricate velocity based player movement script including highly customizable acceleration (Air and Ground), movement, jumping and dashing/crouching!
- Includes a basic Health script including, health, regen and invincibility frames!

Free to use and distribute!
